# Library Management System

High-level overview

- A small library management console program that models books and students, and demonstrates simple operations for managing a library.

Key files

- `LibraryManagmentSystem.java` — main program coordinating library operations.
- `Library.java` — library model and operations.
- `book.java`, `books.java` — book models and collections.

How to run

```bash
cd weekly_project/Library_management_system
javac *.java
java LibraryManagmentSystem
```

What you'll learn

- Applying OOP to model real-world systems.
- Managing collections of objects and simple program flow.
