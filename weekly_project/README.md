# Weekly Projects Overview

This folder contains a set of small Java projects completed as weekly assignments. Each project is self-contained and demonstrates a focused topic in Java programming.

Projects included (excluding the Online Movie Ticket System which already has its own README):

- `Inventory_Management_System` — simple inventory demo using packages and OOP.
- `Library_management_system` — models books and students; demonstrates collection usage.
- `OnlineQuiz` — interactive quiz console app with modular services.
- `The_Memory_game.java`, `Tic_tac_toe_game_week1.java` — small standalone games in the root.

How to explore

- Change into a project folder, compile its `.java` files and run the main class as shown in each project's README.
