# Online Quiz

High-level overview

- A console-based quiz application that loads questions, prompts the user, and scores answers. Designed to demonstrate modular code and simple input validation.

Key files

- `quiz/Main.java` — entry point that runs the quiz.
- `quiz/models/Question.java` — question data model.
- `quiz/services/QuizService.java` — quiz logic and flow.

How to run

```bash
cd weekly_project/OnlineQuiz
javac quiz/**/*.java
java quiz.Main
```

What you'll learn

- Structuring a small Java application into packages and services.
- Handling user input and program flow for interactive console apps.
