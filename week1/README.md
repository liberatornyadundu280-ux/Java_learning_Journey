# Week 1 — Java Basics

Overview

- Introductory Java concepts: primitive types, identifiers, input/output, and basic control flow.

Files included

- `hello.java`, `datatypes_identifiers.java`, `java_loops_input_output_stringtypecasting.java` and small examples.

How to run

```bash
cd week1
javac *.java
java hello
```

Learning outcomes

- Basic Java syntax and program structure.
- Working with primitive types, strings, and simple I/O.
